# 梳理学术脉络

## （1）概念演进 Prompt

```
关于【核心概念，比如：思维链(Chain-of-Thought)】这个概念，在这个术语正式火起来之前，有哪些奠基性的早期论文？

请帮我梳理一条从【起始年份，如2015】到【截止年份，如2022】的技术演进脉络。

详细说明每一篇关键论文是如何启发后者的，它们之间有什么继承或修正关系。
```

## （2）后续改进 Prompt

```
请帮我找到引用了【经典论文题目】的5篇论文，这些论文需满足以下条件：

1. 发表时间在【年份范围，如2020-2024】
2. 在【具体细分方向，如：推理效率提升】有重要突破

请详细说明每篇新论文是如何在【经典论文】基础上进行改进的，解决了原论文的哪些局限性。
```
