# Gemini绘制可编辑的技术路线图教程

## 步骤一：上传材料并生成 Drawio 代码

访问：https://gemini.google.com/app?hl=en

上传文章、参考图和提示词，使用以下提示词生成 Drawio 代码：

```
文件里是我自己的研究内容，你只需要在保持原有结构不变的前提下，把对应的研究内容填入到合适的位置即可，要求整体看起来是一张标准的学术文章技术路线图，各模块之间逻辑清晰、衔接自然，不需要额外解释，只输出完整的技术路线图图示，你是一个Drawio 代码生成器，将我的需求或者图片转化为对应的xml代码
```

或使用以下参考模板提示词：

```
"我给你一张已经成型的技术路线图作为参考模板，
严格按照这张图的整体结构和逻辑顺序来组织内容：
不要自行调整框架层级。
文件里是我自己的研究内容，
你只需要在保持原有结构基本不变的前提下，
把对应的研究内容填入到合适的位置即可。
要求整体看起来是一张标准的学术文章技术路线图。
各模块之间逻辑清晰，衔接自然，
不需要额外解释，
只需要输出完整的技术路线图图示。
你是一个draw.io代码生成器，
将我的需求或者图片转化为对应的xml代码。"
```

## 步骤二：在 Drawio 中生成路线图

访问：https://app.diagrams.net/?src=about

将生成的 Drawio XML 代码复制到 Drawio 中，即可生成完整的技术路线图。
